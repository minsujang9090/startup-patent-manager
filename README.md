
# 📂 사내 특허 관리 시스템 (Patent Manager) v3.0

로컬 엑셀 파일을 기반으로 작동하는 **사내 특허 및 지식재산권(IP) 관리 도구**입니다.
복잡한 특허 비용 납부 기한, 연차료 관리, 히스토리 조회를 웹 대시보드 형태로 직관적으로 제공합니다.

---

## ✨ 주요 기능

1.  **📊 통합 대시보드 (New!)**
    *   **주요 지표**: 전체/특허/디자인/상표 건수 및 긴급 업무(Top 5) 요약.
    *   **인터랙티브 차트 (Altair)**:
        *   **연도별 추이**: 출원 vs 등록 건수 비교 (Grouped Bar Chart).
        *   **상태별 분포**: 진행 현황(등록/심사/포기 등) 비율 시각화 (Donut Chart).
        *   **비용 분석**: 연도 필터(Start~End)를 통한 월별 지출 추이 확인.
    *   **월별 현황**: 납부 **예정 금액** 및 **완료 금액** 자동 집계 (KRW/USD).

2.  **📅 월별 업무/비용 관리**
    *   미납 건(To-Do), 향후 예정 건(Future), 완료 건(Done) 탭 구분.
    *   기한 도래/경과 건에 대한 **붉은색 하이라이트** 경고.
    *   **회신요청기한** 관리 기능 추가.

3.  **🔍 특허별 상세 이력 조회**
    *   특허명/관리번호 검색 및 주요 정보(출원/등록번호) 원클릭 복사.
    *   비용 단계별(출원/등록/유지관리) 지출 통계.
    *   직관적인 타임라인 리스트 제공.

4.  **📝 데이터 입력 및 수정**
    *   신규 특허 및 비용 내역 등록/수정/삭제.
    *   엑셀 파일(**patent_rawfile.xlsx**)과 실시간 양방향 동기화.
    *   **서식 보존**: 엑셀의 기존 스타일(색상, 테두리 등)을 유지하며 데이터만 안전하게 수정.

## 🛠️ 설치 및 실행 방법

### 방법 1: Python 환경에서 실행 (개발자용)

**1. 필수 라이브러리 설치**
```bash
pip install streamlit pandas openpyxl altair
```

**2. 프로그램 실행**

```bash
streamlit run app.py
```

### 방법 2: 실행 파일로 실행 (일반 사용자용)

배포된 폴더 내의 실행 파일을 더블 클릭합니다.

  * `run.exe` (또는 `특허관리시스템.exe`)
  * **주의:** 실행 파일과 `patent_rawfile.xlsx` 엑셀 파일은 반드시 **같은 폴더**에 있어야 합니다.

-----

## 📊 엑셀 데이터 구조 (필수)

프로그램 작동을 위해 `patent_rawfile.xlsx` 파일은 아래 두 개의 시트와 컬럼을 반드시 포함해야 합니다.

### 1\. 시트명: `기본정보(Master)`

특허의 고유 서지 정보를 담습니다.

| 컬럼명 | 설명 | 예시 |
| :--- | :--- | :--- |
| **가산관리번호** | (Key) 고유 식별 번호 | P-23-001 |
| **명칭** | 특허/상표 명칭 | 스마트 센서 장치 |
| **출원인** | 출원인/권리자 | (주)우리회사 |
| **진행현황** | 현재 상태 | 등록, 심사중, 거절 |
| **출원번호** | - | 10-2023-... |
| **출원일자** | YYYY-MM-DD | 2023-01-01 |
| **등록번호** | - | 10-249... |
| **등록일자** | YYYY-MM-DD | 2024-05-20 |
| **설명** | 상세 설명 | 핵심 기술 특허 |

### 2\. 시트명: `비용관리(Schedule)`

납부 기한과 비용 정보를 담습니다.

| 컬럼명 | 설명 | 예시 |
| :--- | :--- | :--- |
| **가산관리번호** | (FK) Master 시트와 연결 | P-23-001 |
| **구분** | 비용 항목 명칭 | 4년차 연차료 |
| **기한(Due Date)** | **납부 기한 (필수)** | 2024-12-31 |
| **회신요청기한** | (선택) 고객사 회신 요청일 | 2024-12-15 |
| **금액** | 숫자만 입력 | 150000 |
| **통화** | KRW 또는 USD | KRW |
| **납부상태** | **'미납'** 또는 **'납부완료'** | 미납 |
| **실제납부일** | 납부 완료 시 기재 | 2024-12-20 |

## 🚀 배포용 EXE 파일 만들기 (PyInstaller)

Python이 설치되지 않은 PC에서 실행하려면 아래 명령어로 빌드하세요.

1.  가상환경 생성 및 필수 패키지 설치 (`streamlit`, `pandas`, `openpyxl`, `altair`, `pyinstaller`)
2.  `run.spec` 파일 확인 (재귀 제한 설정 및 hiddenimports 포함)
3.  빌드 명령어 실행:
    ```bash
    pyinstaller run.spec
    ```
4.  `dist` 폴더에 생성된 `.exe` 파일을 엑셀 파일과 함께 배포.

## ⚠️ 주의사항

1.  **날짜 형식:** 엑셀의 날짜 컬럼은 `YYYY-MM-DD` 형식을 권장합니다. (앱 내부에서 자동 보정 기능 포함)
2.  **데이터 무결성:** `가산관리번호`는 두 시트를 연결하는 핵심 열쇠이므로 오타가 없어야 합니다.
3.  **파일 권한:** 엑셀 파일이 열려있는 상태에서 앱에서 저장을 시도하면 에러가 발생할 수 있습니다.
